# Ethical Hacking Lab

Personal cybersecurity learning laboratory.

## Scope

All security testing is performed only against:
- locally hosted vulnerable applications
- systems I own
- systems for which I have explicit authorization

## Learning Areas

- Network reconnaissance
- Web application security
- SQL injection
- Cross-site scripting (XSS)
- Authentication security
- Access control
- API security
- Vulnerability analysis
- Security automation
- Secure coding

## Laboratory Targets

- OWASP Juice Shop
- OWASP WebGoat
- DVWA

## Tools

- Kali Linux
- Nmap
- Burp Suite
- OWASP ZAP
- Python
- Git/GitHub
